# ADR-0001: Граница подготовительного этапа

- Дата: 2026-11-24, Europe/Moscow.
- Статус: принято для подготовки среды.

## Контекст

Пользователь поручил настроить автономную команду, Git, постоянную документацию и визуальное тестирование. Полное ТЗ LedgerFlow будет передано после подготовки. На момент начала локальная и удалённая история Git пусты, а `main.py` содержит стандартный пример PyCharm.

## Решение

- Создать восемь проектных профилей в `.codex/agents/*.toml`, совместимых с установленным Codex CLI 0.172.0. Обязательные поля: `name`, `description`, `developer_instructions`.
- Ограничить параллельную работу тремя субагентами: с Technical Lead это четыре доступных слота. Назначать одного автора на файл; интеграцию и Git оставить главному агенту.
- Хранить только проектные настройки. Не менять глобальные разрешения, модели, провайдеры и параметры безопасности пользователя.
- Создать независимый стенд проверки Playwright на Node.js с видимым запуском Chromium, замедлением действий и локальными артефактами. Выбор Node.js здесь относится только к инструментам тестирования.
- Не выбирать продуктовый стек и не реализовывать финансовые операции или Chaos Lab до разбора ТЗ.
- Сохранить исходный `main.py` без изменений, исключить локальные файлы IDE и секреты из Git.
- Выполнить первый проверенный коммит в `feat/ledgerflow-build` и push. Не выполнять merge в `main`.

## Последствия

Подготовительный коммит можно воспроизвести и проверить независимо от будущей архитектуры продукта. Стенд не демонстрирует готовность бизнес-функций. После получения ТЗ потребуются отдельные ADR по продуктовым решениям и проверка финансовых инвариантов.

## Источники

- Фактические `codex --version`, `codex --help` и `codex --strict-config app-server --print-startup-config`.
- [Codex: Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents) — проектные TOML-профили и лимит параллельных агентов.
- [Playwright: Configuration](https://playwright.dev/docs/test-configuration), [Videos](https://playwright.dev/docs/videos), [Trace viewer](https://playwright.dev/docs/trace-viewer).

Устаревшие примеры `.cursor/agents/*.md` из установленного вспомогательного навыка не используются: пользователь потребовал конфигурацию актуальной установленной версии Codex.
